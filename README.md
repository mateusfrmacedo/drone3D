
# Drone3D

App nativo para macOS que cria arquivos USDZ usando `RealityKit.PhotogrammetrySession`.

Abra `Drone3D.app` no Finder. Se preferir usar o Xcode, abra `Package.swift` e pressione Run.

O app aceita uma pasta de fotos JPEG, PNG, HEIC/HEIF ou TIFF, permite selecionar a qualidade de geração e mostra progresso, etapa, tempo decorrido, estimativa e erros durante o processamento.

Requisitos: macOS 14 ou posterior e um Mac compatível com `PhotogrammetrySession`.
